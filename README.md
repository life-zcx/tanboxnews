# Tanbox News AI — Автономный B2B-контент-маркетер (ИС МПТ РК)

Автоматическая система мониторинга регуляторных новостей Казахстана, ведения контент-плана и генерации экспертного B2B-контента для **Telegram, Instagram и Threads**.

Бот самостоятельно отслеживает изменения в законодательстве РК, проверяет 13 порталов и Telegram-каналов, ведет календарь дедлайнов КГД и маркировки, замеряет просмотры в `@tanboxkz` и выгружает контент-план в Excel.

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей (один раз)
```bash
pip install -r requirements.txt
```

### 2. Настройка окружения (`.env`)
Файл `.env` уже сконфигурирован. При переносе настройте:
- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather.
- `GEMINI_API_KEY` — ключ Google Gemini API.
- `GEMINI_MODEL` — рабочая модель (`gemini-3.5-flash-lite`).
- `AUTO_POST_CHANNEL_ID` — канал для публикаций (`@tanboxkz`).
- `ADMIN_IDS` — Telegram ID администраторов (`8563274673`).
- `GOOGLE_SHEET_WEBHOOK_URL` — (опционально) URL веб-приложения Google Apps Script для авто-синхронизации.

### 3. Запуск в 1 клик
Дважды кликните по файлу **`run.bat`** (или в терминале: `python bot.py`).

## 🐳 Запуск на VPS сервере (Docker 24/7)

Для круглосуточной работы бота на удаленном сервере (VPS на Ubuntu/Debian):

1. **Скопируйте файлы на сервер** (через Git, SCP или архив).
2. **Запустите одной командой:**
   ```bash
   bash deploy.sh
   # Или вручную:
   docker compose up -d --build
   ```

**Полезные команды на сервере:**
* `docker compose logs -f` — смотреть логи работы бота в реальном времени;
* `docker compose restart` — перезагрузить бота;
* `docker compose down` — остановить контейнер.

*База данных `data/bot.db` сохраняется на сервере в папку `data` и не стирается при перезапусках.*

## 📱 Ключевые возможности системы

### 1. ⏰ Отложенный постинг и Контент-план (Автопилот)
- **Кнопка «⏰ Запланировать»** прямо в карточке любого поста.
- **Быстрые B2B-слоты:** «Завтра в 11:00», «След. вторник 11:00», «След. четверг 11:00» или ручной ввод даты.
- **Режим Автопилота:** бот сам находит ближайший свободный прайм-тайм слот и ставит пост в очередь.
- **Фоновый публикатор:** каждую минуту проверяет очередь и точно в срок выпускает готовый пост в `@tanboxkz`.
- **Просмотр очереди:** кнопка `🗓 Контент-план` показывает все запланированные публикации с возможностью отмены.

### 2. 📅 Календарь дедлайнов регуляторики РК
- Встроенная база ключевых дат Казахстана (ФНО 910.00, ФНО 300.00 по НДС, этапы маркировки обуви, 100% маркировка лекарств, ежемесячные платежи 25 числа, годовые отчеты 100/220).
- **Авто-напоминания за 14, 7 и 2 дня:** бот самостоятельно отслеживает приближение дедлайна, генерирует предупреждающий пост с суммами штрафов в МРП/тенге и нативным предложением Tanbox и присылает админу с кнопкой публикации.
- Кнопка `📅 Дедлайны РК` — просмотр всех дедлайнов со счетчиком оставшихся дней и кнопкой `⚡ Создать пост-напоминалку`.

### 3. 🌐 Мониторинг 13 источников РК (Сайты + Telegram + Открытые НПА)
- **Сайты регуляторов:** Uchet.kz, Tañba (Казахтелеком), Tañba B2B, Inbusiness.kz, Курсив.
- **Telegram-каналы (моментальный перехват новостей):**
  - `ТГ: Параграф Бухгалтер РК` (`@prg_buh`)
  - `ТГ: MyBuh.kz` (`@mybuh_kz`)
  - `ТГ: Uchet.kz Новости` (`@uchet_kz`)
  - `ТГ: Inbusiness.kz` (`@inbusinesskz`)
- **Открытые НПА (`legalacts.egov.kz`):** отслеживание законопроектов и приказов Минторга/Минздрава еще на стадии обсуждения.

### 4. 📈 Аналитика публикаций канала @tanboxkz
- Кнопка `📈 Аналитика @tanboxkz` замеряет реальные просмотры всех опубликованных постов напрямую из Telegram.
- Рейтинг ТОП-5 самых читаемых публикаций канала.
- Экспертные выводы контент-стратегии по вовлекающим темам (штрафы, 1С, аптеки, кассы).

### 5. 📥 Выгрузка контент-плана в Excel/CSV и Google Таблицы
- Кнопка `📥 Скачать Excel/CSV` формирует файл в кодировке **UTF-8 с BOM** (корректно открывается в Microsoft Excel без искажения русских букв).
- Содержит ID, даты, статусы, тексты для всех 3 площадок и счетчики просмотров.
- Готовый шаблон интеграции с Google Таблицами (`docs/google_sheets_sync.js`).

## ⌨️ Команды бота

- `/start` — Главное меню и запуск нижней панели
- `/posts` — Сохраненные посты и черновики с пагинацией
- `/schedule_queue` — Очередь запланированных постов
- `/deadlines` — Календарь дедлайнов Казахстана
- `/analytics` — Аналитика просмотров канала @tanboxkz
- `/export` — Скачать контент-план в Excel/CSV
- `/check_now` — Проверить все 13 источников сейчас
- `/pause` / `/resume` — Управление фоновым мониторингом
- `/sources` — Управление сайтами и каналами
- `/help` — Подробная справка
